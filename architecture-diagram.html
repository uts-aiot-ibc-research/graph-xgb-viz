Request flow

  1. Browser → web: the user hits graph-xgb-web (frontend).
  2. web → api: web calls graph-xgb-api (inference server) server-side.
  3. api → data & secrets: api reads inference inputs from the GCS bucket (/data) and the admin token from Secret Manager.
  4. api → inference & response: api runs inference with the models baked into its image (gnn.pt · pca.pkl · xgb.pkl) and returns the result back through web to the browser.
